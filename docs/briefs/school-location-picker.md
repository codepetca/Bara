# School location picker — 2026-11-19

Goal: teachers choose PETHS then room220/223 in Attendance schedules without approval or manual class linking. Custom is the existing class/legacy-room fallback. Admins manage school rooms in Bara; no duplicated Pika room records.

Flow: Bara admin names the existing room group PETHS under Edit rooms; its location becomes available to signed Pika teachers. Pika shows School location then Room, and saves the class location selection directly. Choosing a different school or Custom resets current room windows and future default; teachers then choose a room normally. Existing custom rooms remain usable; Custom without a room uses the normal class QR. Preserve shared posters, enrollment/ownership checks, and normal room Undo. Location changes themselves have no implicit room choice or attendance marking.

Architecture: additive optional school-location name/key on organizations, bounded indexed discovery exposing only named active locations; admin-only naming. Extend signed rooms list with optional locations/location_id and add staff location command. Preserve existing app_users/auth_identities and roster ownership. Selecting a published location is sufficient; private organizations are not discoverable or newly assignable. Existing explicit catalog grants remain compatible. Naming/location selection does not replace room IDs, poster keys or tablet assignments.

UI: extend existing Edit rooms and native Pika Select/FormField in both schedules and standalone room dialog. No approval screen or new dashboard. Cover loading, no schools, Custom/legacy, saved school, busy, failure/uncertain response, stale class/date/open responses, poster return, location removal/unavailability, room Undo.
