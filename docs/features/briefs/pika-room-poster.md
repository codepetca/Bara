# Print the shared student room poster from Pika

Teachers open Attendance rooms in Pika, choose an administrator-managed Bara room, and print its current student poster. The signed `poster` room command requires the existing verified teacher and class catalog grant and returns the existing room poster path. It works while attendance is closed. An administrator-disabled poster returns an unavailable state in Pika.

Pika uses its configured Bara display origin with the validated path and its existing QR poster layout. Each preview opening reads the current poster. Room 223 must print the same stable URL as Bara, keeping the current tablet pairing and accepting only eligible student enrollments during open attendance.

Verify signed command scope, disabled/replaced posters, and closed attendance, then decode the actual Pika print output and compare it with the current Room 223 poster URL. Inspect desktop and phone preview and isolated print output.
